# 九龍城ライフシミュレーター4 🏙️

`kowloon-life3`(v3)をベースにした**大型アップデート版(v4)**です。恋人システム・季節イベント・6つの新施設・店システムなどを追加しました。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life4_save_v1`)。会話ノード総数 **623本** / 手紙 18種。

## 起動

```bash
cd kowloon-life4
python3 -m http.server 8000
# → http://localhost:8000
```

## v4 での追加・修正(要望対応)

### 💗 恋人システム
- 主要人物**5人(ムニ以外)**の誰か1人と恋人になれる。**恋人は1人だけ**。
- 親密度が**唯一無二(90+)**になった相手に施設/自宅で話しかけると**告白イベント**。OKで恋人、断れば唯一無二のまま。
- **ゲイカップル制約**: レニィ/ヒュウ/ジンパチのうち2人が既に恋人同士なら、その相手とは恋人になれない。逆に、プレイヤーの恋人になったこの3人の誰かは、他の2人とゲイカップルにはならない。
- **ゲル**はムニ以外の主要人物と恋人になれるが、その相手に既に恋人(プレイヤー/カップル)がいれば不可。
- **ムニは子供なので家族の絆**(親密度90+で家族イベント)に。
- **恋人特有の会話**(プレイヤー×恋人)、**ムニは家族特有の会話**、**NPC同士の恋人特有の会話**を実装。恋人からの手紙も届く。
- **恋人・仲良し同士は一緒に出かける/互いの部屋に遊びに来る**(相互親密度60+で相互訪問、恋人はさらに強く)。

### 🎉 季節イベント(集会所=ガチャ施設)
- **集会所**をガチャで実装。季節の特定の日(中頃)に主要人物が集会所へ集合して会話。**仲良ければ小暮カネも参加**。
- **お花見**(春): 桜が咲き、翌日消える。 **七夕**(夏): 笹を飾り、**主要6人+全NPCの願い事**を笹クリックで一人ずつ読める。翌日消去。 **ハロウィン**(秋)。 **クリスマス**(冬): ツリーを飾り翌日消去。 **正月**(冬)。

### 🍰 ガチャ新施設(性格に沿った施設会話つき)
- **ケーキ屋**(ヒュウ/ムニ/ゲルら)。**病院**: 主要人物が病気になり、**話しかけるとお見舞い扱いで好感度UP**。**ミニ水族館**: レニィが主に来て海・魚の話。**魚屋**: ネオが主に来て**魚のさばき方を実演**(魔法剣士の剣技として)。**焼肉屋**: ジンパチが主に来て、**みんなで焼肉を食べる会話**も。

### 🛍️ コンビニ店員 + 店システム
- **コンビニ店員リン**をNPCとして追加。話しかけると**贈り物カウンター**が開く。
  - **絆の贈り物**: プレイヤーと選んだ相手の親密度+8(対象選択画面)。
  - **仲人の贈り物**: 主要人物2人を選び、その2人の相互親密度+8(2人を順に選択)。

### 🥷 泥棒の修正
- コソ泥は**ランダムな時間帯だけ**コンビニに出現。**いない時間帯はメッシュを非表示**(居座らなくなった)。

### 💬 会話・演出の改善
- **吹き出しの重なりを修正**: 1キャラ1吹き出しに統一し、雑談中はその場の周囲のバークを抑制。雑談の吹き出しは少し高い位置に。
- **各施設での主要人物どうしの会話を大幅増量**(ケーキ屋/病院/水族館/魚屋/焼肉屋/屋上/床屋/花屋ほか)。
- **カラオケ**: 2人以上来やすくし、**デュエット**会話を追加。
- **手紙のバリエーションを増量**(季節便り全6人+恋人からの手紙+NPC文通お知らせ、計18種)。
- **ネオの魔法剣士設定**を各所の会話に反映(見回り・魚のさばき・雨の魔剣ネタ等)。

### 🧪 テスト機能(削除可能・v3から拡張)
- 右下🧪ボタン: 好感度スイッチ(他人〜唯一無二)・全施設建設に加え、**季節イベントの日にする**・**誰か病気に**・**恋人リセット**を追加。`js/testtools.js` の削除+`TEST_MODE=false` で完全除去。

```

│   ├── data/
│   │   ├── events.js       # ★新規: 季節イベント暦・七夕の願い事
│   │   ├── dlg_v4.js       # ★新規: 告白/恋人/カップル/イベント集合/新施設ペア/デュエット/魔法剣士
│   │   ├── chars.js        # コンビニ店員 / ROMANCEABLE・GAY_TRIO / ペア拡張
│   │   ├── facilities.js   # 集会所/ケーキ/病院/水族館/魚屋/焼肉屋
│   │   ├── facility_talk.js # 新施設の施設会話 + 店員
│   │   ├── schedules.js    # 新施設・カラオケへの誘導 + 店員
│   │   └── letters.js      # 手紙18種に増量(恋人手紙ほか)
│   ├── sim/

│   │   └── npc.js          # イベント集合 + 相互訪問/一緒に出かける
│   ├── three/
│   │   ├── events3d.js     # ★新規: 桜/笹/ツリー/かぼちゃ/門松の3D
│   │   ├── floors.js       # 新施設6種の内装
│   │   └── characters.js   # 店員の見た目
│   ├── game.js             # イベント制御/病気/泥棒時間限定/店UI/七夕UI/吹き出し修正
│   └── testtools.js        # イベント再現・病気・恋人リセット追加
└── index.html              # 店/七夕/対象選択モーダル
```

その他の中核システムは v1〜v3 と同一です。詳細は各版の README を参照してください。
