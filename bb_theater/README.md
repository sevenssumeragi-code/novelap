# 🎬 BB劇場メーカー

「BB劇場」風のコント紙芝居を**自動作成して上演し、動画として保存できる**Webアプリです。
画面上部にキャラクターの立ち絵と場面背景、画面下部に物語のナレーション・会話ウィンドウを
表示する、おなじみのレイアウトで上演します。

## できること

| 機能 | 内容 |
|---|---|
| 物語の自動作成 | 登場人物の設定とテーマから、Claude が起承転結+オチつきの台本(JSON)を自動生成 |
| 自動演出 | その時話している/登場しているキャラだけを舞台に配置し、話者はBB風にバウンド。感情(怒・喜・哀・驚など)も演出 |
| 場面転換 | シーンごとにAIが背景(部屋・公園・教室・コンビニ・夜の街など8種 × 昼/夕/夜)を選択し、フェードで転換 |
| AIによるBGM選曲 | シーンの空気に合わせてAIがBGMムード(コミカル/日常/緊迫/悲哀/決戦/ほのぼの/ホラー)を選曲し、Web Audio がリアルタイム演奏 |
| 登場人物の設定欄 | 名前・設定・口調・一人称を記入。AIはこれを厳密に守って台本を書く |
| 外見のアップロード欄 | キャラ画像をアップロード可能。グリーンバックのBB素材はワンクリックでクロマキー透過。画像がなくてもシルエットで出演 |
| 動画ダウンロード | 「🎥 動画を録画してダウンロード」で最初から自動上演し、BGM・効果音込みの WebM 動画として保存 |

## 起動方法

```bash
pip install -e .
export ANTHROPIC_API_KEY=sk-ant-...   # 物語のAI生成に必要
bb-theater                             # → http://127.0.0.1:8010 を開く
```

APIキーが無くても「サンプル劇場」ボタンで上演・録画の動作確認ができます。

## 使い方

1. 右パネルの **👥 登場人物** でキャラの名前・設定を書き、外見画像をアップロード(任意)
2. **📖 物語をつくる** でテーマを入れて「✨ AIで物語を自動作成」
3. 台本が完成すると自動で上演開始。クリックでセリフ送り、オートON で全自動上演
4. **🎥 動画を録画してダウンロード** を押すと、最初から自動上演して終劇後に WebM を保存

## 注意

- 生成される台本は全年齢向けのパロディ・コメディ調です(過激な表現はプロンプトで禁止しています)。
- 録画はブラウザの MediaRecorder を使うため、Chrome / Edge / Firefox を推奨します。
- キャラ設定・画像・直近の台本はブラウザの localStorage に保存されます。
