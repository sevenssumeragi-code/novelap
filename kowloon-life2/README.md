# 九龍城ライフシミュレーター2 🏙️

`kowloon-life`(v1)をベースに、フィードバックを反映した**改善版(v2)**です。設計書a(統合版)とNPC会話システム総合設計書(KLN-DLG-001)の構造はそのまま、会話量と施設演出を大幅に増やしました。

Three.js 同梱・ビルド不要・完全オフライン。セーブは v1 と別枠(`kowloon_life2_save_v1`)なので独立して遊べます。

## 起動

```bash
cd kowloon-life2
python3 -m http.server 8000
# → http://localhost:8000
```

## v2 での改善点(要望対応)

### 1. 喫茶クーロンに女性店員を新設
- **看板娘サチ**(NPC)を追加。ポニーテール+エプロンの3Dモデル、専用スケジュール(開店中は喫茶店常駐)。
- **ヒュウとの三者会話**を実装(設計書 第15.2節「女性店員の場合の口説き会話」)。ヒュウ在店中にサチへ話しかけると、上品で害のない(CERO A)口説き→受け流しのやりとりが発生。ヒュウ×サチの立ち話(AMBIENT)も追加。

### 2. 主要人物どうし・NPCとの会話をもっと発生しやすく
- **AMBIENTを cast方式に刷新**。2人=雑談、**3人=グループ会話**に対応。
- 出やすさを改善: スキャン間隔 10分→**5分**、雑談後クールダウン 60分→**20分**、同ノード再選択 360分→**150分**に短縮。さらに**フロアに入った瞬間その場の立ち話をスキャン**。
- 相互ペアを 8→**30ペア**に拡張。**小暮カネ×主要6人**、床屋×ジンパチ/ヒュウ、郵便屋×レニィ/ムニ、サチ×ヒュウ/ゲル/レニィなど、街の人と主要人物の会話を多数追加。
- 主要人物どうしの2人会話も増量(ヒュウ×ネオ、ジンパチ×ネオ、ジンパチ×ムニ、レニィ×ゲルほか)。

### 3・4. 通常会話・全体の会話バリエーションを増量
- 各主要人物に汎用・条件付き・**レア会話**(weight低の「本音」)を追加。
- 会話ノード総数 **239 → 445本**(各主要人物 約55〜61本)。

### 5. 家具設置トリガー会話を増量
- 家具ごとの専用会話(`dlg_furniture.js`)を新設。DSLに `has_furniture(char, item)` を追加し、**その家具を本人の家に置くと専用セリフ**が出る(例: レニィの雲ベッド、ネオの黄金の玉座)。好みタグ総合の「部屋完成」会話も追加。

### 6. 施設が増えるほど拾えるコインが増える
- `coinsForDay(店数) = 3 + 店数 × 1.5`。初期4店で1日9枚、店を増やすたび +1〜2枚に増加(決定論配置は維持)。

### 7. 九龍マートでの主要6人の会話を増量
- 6人全員ぶんの市場専用会話を複数用意(卵の持ち方、プロテイン肉、おつかい、値札の考察…)。カネの市場会話も追加。

### 8. 全ての施設に専用会話を設置
- `facility_talk.js` に**全13施設ぶんの施設専用会話**を宣言的に収録し、`DialogueDirector` 用ノードへ自動展開。各施設に入って住人に話しかけると、その施設ならではのセリフが出る。

### 追加施設: 銭湯
- 主要人物が夕方に利用するよう時間割を調整。**男性5人が19時台に集合 → 男湯グループ会話(3人)**が発生。
- **ゲルは唯一の女性なので、男性陣が上がった21時台に単独で女湯へ**。専用ソロ会話あり(壁越しに男湯の笑い声が聞こえる、など)。

## 検証

```bash
node tools/validate.mjs
```
会話ID重複 / 条件DSL文法 / 禁止語(ゲルの「貴様」自動リジェクト) / フォールバック保証 / 未登録参照 をチェック。**445ノード 全チェック合格**。
