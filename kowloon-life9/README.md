# 九龍城ライフシミュレーター9 💬

`kowloon-life8`(v8)をベースに、**主要人物の会話バリエーションをさらに大量追加した版(v9)**です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life9_save_v1`)。会話ノード総数 **982本** / 手紙 **38種**。

## 起動

```bash
cd kowloon-life9
python3 -m http.server 8000
# → http://localhost:8000
```

## v9 での追加(要望対応)

新規会話ノードを65本追加。以下の5カテゴリを増量しています。

### 💕 (1) プレイヤー×主要6人 恋人会話
- レニィ/ヒュウ/ジンパチ/ゲル/ネオの恋人専用会話を各3本、ムニ(家族)を2本追加。時間帯・季節・天気の条件つきで入れ替わる。

### 👫 (2) 主要人物どうしのNPCカップル会話
- ヒュウ×レニィ / ジンパチ×ネオ / ゲル×ネオ / ヒュウ×ジンパチ / レニィ×ネオ / ゲル×ヒュウ / ジンパチ×レニィ の甘い立ち話を追加(カップル成立時のみ発火)。

### 💬 (3) 主要人物2人の通常会話
- 屋上・路地などの場所別、朝/夜/真夜中の時間帯別、春夏秋冬の季節別、雨/晴れ/くもりの天気別の二人組会話を多数追加。

### 🤝 (4) 恋人ではないが仲良くなった2人の会話
- 相互親密度が高い(≧55)が恋人ではない二人組の「親友」会話を7組追加(ヒュウ×レニィ、ゲル×ネオ、ジンパチ×ヒュウ、レニィ×ムニ、ゲル×ジンパチ、ヒュウ×ムニ、レニィ×ジンパチ、ムニ×ネオ)。

### 🏪 (5) 各施設・店での会話
- 喫茶店・床屋・ラーメン・駄菓子屋・ケーキ屋・ゲーセン・本屋・花屋・銭湯・水族館・居酒屋・玩具屋・コンビニ・焼肉・映画館・ドーナツ屋・教会・カラオケ・集会所での主要人物ペア会話を追加。

## 検証

```bash
node tools/validate.mjs   # 982ノード 全チェック合格
```

ブラウザ実機テストで確認済み: (1)恋人会話6人ぶん / (2)NPCカップル7組 / (3)通常2人会話 / (4)仲良し(恋人でない)7組 / (5)各施設会話10種以上、すべて発火。コンソールエラーなし。
