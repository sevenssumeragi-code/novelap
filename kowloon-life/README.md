# 九龍城ライフシミュレーター 🏙️

「九龍城ライフシミュレーター 開発設計書(統合版)」および「NPC会話システム総合設計書 (KLN-DLG-001)」に基づいて実装した、ブラウザで動く生活シミュレーションゲームです。

Unity+5年運用前提のフル仕様のうち、**中核システムを設計書の構造のままデータ駆動で実装した垂直スライス**です。Three.js 同梱・ビルド不要・完全オフラインで動きます。

## 起動

```bash
cd kowloon-life
python3 -m http.server 8000
# → http://localhost:8000
```

## 実装している設計書のシステム

### 世界 (設計書a 第2章§2.5 / 会話設計書 第10章)
- **GameClock**: 1ゲーム日=実24分。一時停止/1x/3x/10x。時間帯 MORNING/DAY/EVENING/NIGHT/MIDNIGHT
- **天候** (晴れ/くもり/雨) を日次で決定論抽選。雨はパーティクル+照明+NPC行動+会話に波及
- **季節** (春夏秋冬)。昼夜で照明・空・星が変化

### NPC生活AI (設計書a 第7章 層1 / 会話設計書 第9章)
- 主要住民6人+主要NPC3人(床屋のオヤジ・小暮カネ・郵便屋サン)が**スケジュール定義**でタワー内を移動
- 施設未建設/閉店時のフォールバック、天候例外(雨→屋内)、条件DSLによる上書き
- ジンパチは朝の階段ダッシュ、ゲルは夜型、ムニは午後レニィに引っ付く、カネは軟化すると喫茶店に来る

### 会話システム (会話設計書 第1〜4章) — **239ノード**
- **条件DSL**: `time == NIGHT and weather == RAIN and rank(PC, LENNY) >= 3` をロード時コンパイル(実行時パース禁止)。マクロ `@kane_soft` 等も設計書どおり
- **プールスタック**: EVENT(85) > 施設(65) > 状態(45) > 条件付き(30) > 汎用(10)。特異性ボーナス付き重み抽選
- **DialogueType**: TALK / EVENT(選択肢・once) / BARK(頭上吹き出し) / AMBIENT(NPC同士の雑談)
- **フォールバック保証**: 主要人物は無条件汎用5本以上 (バリデータで強制)
- **盗み聞き**: 同ロケーションの定義済みペアが雑談。最後まで聞くとINFO獲得+ログ登録

### 口調正準 (設計書a 第1章§1.8【正準】)
- レニィ「僕/だよ/だよぉ」・ヒュウ「敬語ナルシスト/レニィ呼び捨て/ジンパチくん」・ジンパチ「俺/だぜ/だろ!」
- ムニ「ムニ(名前呼び)/なの/だもん」+口癖「むにゅ〜」は頻度制御(約1/5)
- ゲル「私/あんた/だな」— **「貴様」は禁止語バリデータで機械的にリジェクト**
- ネオ「私/貴様/である/したまえ」騎士装(マント+装飾剣の3Dモデル)

### 親密度 (会話設計書 第6章)
- 0-100、ランクS0(他人)〜S6(唯一無二)。会話+1〜2、**日次上限+3**
- 成長係数: ムニ×1.3(人懐こい)、**ネオ×0.5**(最難)。ネオは INFO_NEO_PAST_* を集める「**心を開く鍵**」設計(第16.4節)
- **相互親密度**: 定義済みペアのみ変動(レニィ×ヒュウ×ジンパチは×1.5、ネオ×カネの口喧嘩など8ペア)
- **小暮カネ軟化**: kane_softness = 主要6人の対PC親密度平均。毒舌→温度→世話焼きの3段階で全会話が変化

### 手紙 (会話設計書 第7章)
- **スロット×バリアント組立**: 同じ手紙でも天候・季節・思い出(クエスト達成/建設済み施設/獲得INFO)で文面が変わる
- ランク到達手紙(6人)+季節の便り。コイン同封あり
- **返信は3択スタンプ**。選択は `last_reply()` として次の手紙の条件になる

### 噂・情報・辞典 (会話設計書 第13・14・18章)
- **噂**: 床屋発「ネオの金髪」・カネ発「ジンパチの甘党」・ヒュウの創作噂。**本人に確かめる**選択肢が出現
- **INFOトークン**: 知識が会話・イベント・辞典を解放。複数ソースから取得可能(一本道防止)
- **人物辞典**: アンロック段落+出典表示。親密度ゲージ+ランク表示
- **会話ログ**: 盗み聞き・イベントを恒久保存(200件リング)

### 経済・ガチャ (設計書a 第1章§1.9-1.10)
- **2通貨**: 城内コイン(探索・ガチャ)/ 圓(家賃収入・建設費)。毎朝6時に家賃入金(最低保証あり)
- コインは**毎日、商業施設の物陰に決定論で隠し直される** (worldSeed+日でシード導出、§5.11)
- **ガチャ**: N/R/SR/UR、**天井30回でUR確定**、施設開業権のかぶりはレアリティ別コイン還元
- **増築**: 開業権+圓で新施設(ラーメン屋・ゲーセン・銭湯・本屋・駄菓子屋・花屋・カラオケ・薬局・居酒屋)をタワーのてっぺんへ。階段自動接続。住人のスケジュールが即座に変わる

### 模様替え・好みタグ (設計書a 第1章§1.8.7 / 第6章§6.6)
- 6人の家は家具のドラッグ移動・回転・収納・配置が自由
- 家具に tasteTags、住人に好みタグ。**一致する家具を置くと親密度ボーナス+専用会話**
- **お願いイベント**: ムニ「よるこわいの」→ランプを置くと達成、ジンパチ「畳が欲しい」→畳を置くと達成(会話→建築→報酬会話の連鎖)

## コンテンツ検証 (会話設計書 第21章 / 設計書a §4.9)

```bash
node tools/validate.mjs
```

- 会話ID重複 / 条件DSL文法 / 未登録フラグ・INFO・噂の参照 を検出
- **禁止語チェック**: ゲルのセリフに「貴様」が含まれたら自動リジェクト
- フォールバック保証(汎用5本以上)、ムニの口癖頻度チェック

## ファイル構成

```
kowloon-life/
├── index.html            # UI (HUD/会話/手紙/辞典/ログ/ガチャ/増築)
├── js/
│   ├── core/             # dsl.js(条件DSL) clock.js(時計/天候/季節) rng.js(決定論RNG)
│   ├── data/             # 全コンテンツはデータ定義 (設計書0.6「データ駆動」)
│   │   ├── chars.js      # 口調正準・好みタグ・成長係数・ペア定義
│   │   ├── facilities.js # 施設(営業時間/建設費) / schedules.js # 生活時間割+マクロ
│   │   ├── registry.js   # フラグ/INFO/噂/辞典 (レジストリ登録制)
│   │   ├── dlg_*.js      # 会話DB 239ノード (キャラ別+NPC+雑談)
│   │   ├── letters.js    # 手紙テンプレート (スロット×バリアント)
│   │   └── furniture.js  # 家具+ガチャテーブル(天井/重複還元)
│   ├── sim/              # world.js(状態/親密度/効果) dialogue.js(Director) npc.js(スケジュール) letters.js
│   ├── three/            # 3D自動生成 (フロア/内装13種/家具28種/キャラ9人)
│   └── game.js           # オーケストレータ
└── tools/validate.mjs    # コンテンツCI検証
```

## 設計書との対応 (実装スコープ)

フル設計書のうち今回のスライスに含めたのは上記。Unity/ECS・AI生成サービス(AssetSpec パイプライン)・同行システム・懺悔室・500人スケール等は、設計書の将来フェーズ(第10章ロードマップ/第23章拡張)として本実装のデータ駆動構造(条件DSL・プール・レジストリ)にそのまま追加できる形にしてあります。
