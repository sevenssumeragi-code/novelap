# 九龍城ライフシミュレーター17 🐱🐕🐦

`kowloon-life16`(v16)をベースに、**屋上の猫・鳥/地上の犬の登場と主要人物6人の会話 / 集会所イベント会話のさらなる増量 / 主要人物ペア会話の増量**を加えた版(v17)です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life17_save_v1`)。会話ノード総数 **1398本** / 手紙 **41種**。

## 起動

```bash
cd kowloon-life17
python3 -m http.server 8000
# → http://localhost:8000
```

## v17 での追加(要望対応)

### 🐱🐦🐕 動物がやってくる + 主要人物6人の会話
- **屋上に猫と鳥**、**一階の外(地上)に犬**が昼(朝/昼/夕)にやってくる。低ポリの3Dモデルで、ぶらぶら歩き回り、猫はしっぽ、鳥は羽ばたき、犬はしっぽを振る。夜になると帰る(非表示)。
- **主要人物6人それぞれ**が、屋上の猫・鳥、地上の犬に反応する会話を追加(レニィは猫とお昼寝、ネオは鳥や忠犬を騎士目線で、ムニは犬とボール遊び…など)。2人組で動物を話題にする立ち話も。

### 🎉 集会所イベント(誕生日/クリスマス等)の会話をさらに大幅増
- クリスマス・正月・お花見・誕生日会(ムニ/ネオ)に**さらに別バージョンの集合会話**を追加。

### 💬 主要人物6人どうしの会話をさらに大幅増
- 各施設来店時・恋人時・友人時・恋人/友人×施設・時間帯/季節/天気ごとのペア会話を追加。
