# 九龍城ライフシミュレーター6 🏙️

`kowloon-life5`(v5)をベースに、**会話と手紙をさらに拡充した版(v6)**です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life6_save_v1`)。会話ノード総数 **733本** / 手紙 **32種**。

## 起動

```bash
cd kowloon-life6
python3 -m http.server 8000
# → http://localhost:8000
```

## v6 での追加(要望対応)

### ☕🏪 喫茶店サチ × コンビニ店員リン の会話(複数)
- 看板娘どうし仲良しの二人の会話を複数追加(コンビニ・夜勤・雨の日など)。差し入れのプリン、ヒュウの口説きへの愚痴、休みを合わせて遊ぶ約束…など。サチ・リンそれぞれが相手について語る会話も。
- サチが仕事帰りにコンビニ(リンの店)へ立ち寄るようスケジュールを調整。

### 💋 ヒュウがコンビニのリンも口説く
- ヒュウがコンビニでリンを口説く会話を追加(サチに続く「看板娘コレクター」)。**リンはプロらしく丁寧に受け流します**(「肉まん150円です♪」)。害のない上品なやりとり(CERO A)。

### 💬 各施設での主要人物ペア会話をさらに増量(通常/季節別/天気別)
- **季節別**(春夏秋冬)のペア会話を多数追加。 **天気別**(雨/晴れ/くもり)のペア会話も追加。 各施設(喫茶/居酒屋/本屋/床屋/焼肉/薬局/水族館/ゲーセン/市場)の通常ペア会話もさらに増量。

### 🗣️ 通常の主要人物の会話をさらに増量
- 各キャラに時間帯・天気・季節条件の会話を追加。時間経過で入れ替わり、テストではネオ1人で6日ぶんまわして**29種**の会話が出ることを確認。看板娘二人に触れる会話も。

### ✉️ 手紙をさらに増量(25種 → 32種)
- 特別な相手(S5)マイルストーンの便り(ヒュウ/ネオ/ムニ)、看板娘サチ・リンからの便り、駄菓子屋のおばあさんからの便り、冬の雪の便り など。

## 検証

```bash
node tools/validate.mjs   # 733ノード 全チェック合格
```

テストで確認済み: サチ×リンの会話発火 / ヒュウのリン口説き(会話+立ち話) / 天気別ペア会話 / 通常会話が時間・天気・季節で29種以上に入れ替わること。
