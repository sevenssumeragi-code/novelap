# 九龍城ライフシミュレーター7 ⛪

`kowloon-life6`(v6)をベースに、**教会(マルタン神父)を追加し、会話バリエーションを大量に増やした版(v7)**です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life7_save_v1`)。会話ノード総数 **837本** / 手紙 **32種**。

## 起動

```bash
cd kowloon-life7
python3 -m http.server 8000
# → http://localhost:8000
```

## v7 での追加(要望対応)

### ⛪ 教会をガチャに追加 + マルタン神父NPC + 懺悔室
- **九龍聖堂**をガチャの入手施設に追加。祭壇・金の十字架・ステンドグラス5枚・信徒席・ろうそく・シャンデリア、そして**懺悔室**(格子窓つきの木の小部屋)を自動生成。
- **マルタン神父**を追加。真面目で心優しい老人で、話し方は「〜ですな」「〜ですぞ」。**黒髪+白い法衣**(赤い襟・金の胸十字架)。終日、聖堂で懺悔を聞いている。
- 主要人物6人が聖堂に立ち寄るようスケジュールを調整。**懺悔室で、6人それぞれの悩みや後悔にマルタン神父が静かに耳を傾ける会話**を各人ぶん用意(レニィの眠りと海の夢/ヒュウの「完璧という鎧」の疲れ/ジンパチの鍛錬への不安と隠れ甘党/ムニの夜の怖さ/ゲルの古い写真と密かな優しさ/ネオの故郷を捨てた懺悔…など)。懺悔を通して人物INFOが解放される。

### 💕 恋人会話(プレイヤー×主要人物)をさらに増量
- レニィ/ヒュウ/ジンパチ/ゲル/ネオの恋人専用会話を各3本追加(通常+天気/季節/時間条件つき)。ムニは**家族**として3本追加。

### 👫 NPCカップル(主要人物どうし)の会話を増量
- カップルが成立した二人組(ヒュウ×レニィ、ジンパチ×ネオ、ゲル×ネオ、ヒュウ×ジンパチ、レニィ×ネオ、ゲル×ヒュウ)の甘い立ち話を追加。**カップル成立時のみ**発火。

### 🤝 「親しい友人だが恋人ではない」二人組の会話を追加
- 相互親密度が高い(≧55)が恋人ではない二人組の「親友」会話を追加(ジンパチ×レニィ、ヒュウ×ゲル、ネオ×ジンパチ、ゲル×レニィ、ヒュウ×ネオ、ジンパチ×ムニ、ゲル×ムニ)。

### 💬 通常の主要人物どうしの会話をさらに増量
- 場所別(屋上/路地/喫茶/カラオケ/駄菓子屋…)・季節別・天気別の二人組会話を多数追加。各キャラの一人語り(時間帯/季節条件)も増量。マルタン神父に触れる一人語りも。

### 🏪 各施設/店での会話バリエーションを増量
- 教会の施設専用会話(主要6人 + マルタン神父)を追加。本屋・ラーメン・水族館・居酒屋・ケーキ・銭湯・花屋・玩具屋・焼肉での主要人物ペア会話、カネ×ムニの市場会話などを追加。
