# 九龍城ライフシミュレーター16 👶

`kowloon-life15`(v15)をベースに、**ムニのダダこね喧嘩の追加 / 集会所イベント会話のさらなる増量 / 主要人物ペア会話の増量**を加えた版(v16)です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life16_save_v1`)。会話ノード総数 **1358本** / 手紙 **41種**。

## 起動

```bash
cd kowloon-life16
python3 -m http.server 8000
# → http://localhost:8000
```

## v16 での追加(要望対応)

### 👶 喧嘩システムにムニを追加(激しくない「ダダこね」)
- ムニとまだ打ち解けていない相手(相互親密度40未満: ヒュウ/ジンパチ/ゲル/ネオ)との間で、**ムニがダダをこねて相手が付き合わされる**やりとりが発生(激しい喧嘩ではなく、甘えん坊のわがまま)。
- **後日ムニが自分から謝り、相手が優しく褒める**シーン(「えらいね」「賢いね」「立派な騎士だ」など)。仲直りすると相互親密度が上がり、以後は起きなくなる。
- ※既存の主要人物どうしの激しい喧嘩(ネオ絡み等)とは別枠の、ほのぼのした掛け合いです。

### 🎉 集会所イベント(誕生日/クリスマス等)の会話をさらに大幅増
- 七夕・ひな祭り・こどもの日・怪談クラブ・ミニ夏祭り・花火大会・誕生日会(ヒュウ/レニィ/ジンパチ/カネ)に**別バージョンの集合会話**を追加。同じイベントでも毎回違う掛け合いに。

### 💬 主要人物6人どうしの会話をさらに大幅増
- 各施設来店時・恋人時・友人時・恋人/友人×施設・時間帯/季節/天気ごとのペア会話を追加。
