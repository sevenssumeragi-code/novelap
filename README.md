# Novel Forge — 面白さ最優先の小説生成アプリ

Claude(デフォルト: **Claude Fable 5**)を使って、高度で高品質な長編小説を**完成**させるアプリです。
「続きが気になる」「予想外なのに後から納得できる」物語を、単発のプロンプトではなく
**構造(パイプライン+状態管理)** で保証するように設計されています。

## なぜ面白い文章が出るのか(設計思想)

| ユーザー要件 | アプリでの実現方法 |
|---|---|
| 予想外なのに後から納得できる展開 | 企画段階で最初に**【裏の真相】**を設計し、すべての反転をそこから逆算する |
| 伏線と回収/伏線未回収の禁止 | **伏線台帳**(`bible.json`)で「張った話/回収した話」を機械的に追跡。未回収一覧を毎話の執筆コンテキストに注入する |
| 矛盾の少なさ | 毎話確定後に構造化出力で**要約・状態変化を抽出**し、次話の執筆時に全要約+前話ラスト600字を渡す |
| キャラの口調・性格の一貫性/キャラ崩壊禁止 | キャラ設計時に**セリフサンプル3つ**を必ず作り、執筆時に「厳密に従う」よう拘束する |
| 3〜5話ごとの大事件、危機→安心→再危機→反転 | プロット生成プロンプトの**必須条件**として構造化。各話に「リズム上の位置づけ」を明記させる |
| 関係性の変化(仲良し固定禁止) | 毎話「関係性の変化」をプロットで義務化し、変化履歴をバイブルに記録する |
| 感情シーン/引きで終わる/会話だけで進めない | 執筆プロンプトの条件+**自己批評リライト**(10項目チェックリスト)で二重に担保 |
| ご都合主義・意味のない死亡などの禁止事項 | 全ステージ共通のシステムプロンプト「執筆憲章」に明記し、リライト時にも再検査 |

生成は5段パイプラインです:

```
① 企画(裏の真相の設計) → ② キャラクター(全員に秘密・弱さ・恐れ・願望)
→ ③ 全話プロット(事件配置・伏線計画) → ④ 各話執筆(バイブル注入)
→ ⑤ 自己批評リライト → バイブル更新(要約・伏線・関係変化を構造化抽出)
```

## セットアップ

```bash
pip install -e .
export ANTHROPIC_API_KEY=sk-ant-...   # または `ant auth login` 済みならそのままでOK
```

## 使い方(Web UI)

```bash
novel-forge serve
# → http://127.0.0.1:8000 を開く
```

画面から「プロジェクト作成 → ①企画 → ②キャラ → ③プロット → ④次の話を書く」の順に
進めるだけです。生成はリアルタイムでストリーミング表示され、伏線台帳の状態
(未回収/回収済み)がサイドパネルに常に表示されます。

## 使い方(CLI)

```bash
novel-forge new "硝子の来訪者" --genre ミステリー --idea "廃校に転校してきた少年" --episodes 12
novel-forge build <slug>            # 企画→キャラ→プロットを一括生成
novel-forge write <slug>            # 次の1話を執筆(草稿→自己批評リライト)
novel-forge write <slug> --all      # 最終話まで連続執筆
novel-forge status <slug>           # 進捗と伏線台帳
novel-forge export <slug>           # 全話を1つの Markdown に結合
```

`<slug>` はプロジェクト作成時に表示されるID(`novel-forge list` で一覧)。
`--fast` を付けると自己批評リライトを省略できます(速い・安い・品質は下がる)。

## 成果物の場所

```
projects/<slug>/
  concept.md        企画書(裏の真相を含む ※ネタバレ注意)
  characters.md     キャラクター設定
  plot.md           全話プロット+伏線一覧表
  episodes/ep001.md 各話本文
  bible.json        ストーリーバイブル(伏線台帳・要約・関係変化)
```

## モデルとコスト

- デフォルト: `claude-fable-5`(1Mコンテキスト、思考常時オン)。
  安全分類器により拒否された場合は同一リクエスト内で `claude-opus-4-8` に自動フォールバックします。
- コストを抑えたい場合: `export NOVEL_FORGE_MODEL=claude-opus-4-8`
- 思考の深さ: `export NOVEL_FORGE_EFFORT=high`(既定。`xhigh` でさらに深く、`medium` で安く)
- 長編の執筆は1話あたり数分かかることがあります(草稿+リライトの2パス)。

## 注意

- 執筆中(1話分)は完了までブラウザ/ターミナルを閉じないでください。
- `projects/` は `.gitignore` 済みです。作品を残したい場合は別途バックアップしてください。
