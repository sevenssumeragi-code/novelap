# 九龍城ライフシミュレーター5 🏙️

`kowloon-life4`(v4)をベースに、**会話・手紙・交流をさらに拡充した版(v5)**です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life5_save_v1`)。会話ノード総数 **674本** / 手紙 25種。

## 起動

```bash
cd kowloon-life5
python3 -m http.server 8000
# → http://localhost:8000
```

## v5 での追加(要望対応)

### ✉️ 手紙をさらに増量(18種 → 25種)
- 親しい友人(S4)マイルストーンの便り(レニィ/ジンパチ/ゲル)。
- 季節イベントのお礼状(ムニ)、小暮カネ・床屋のオヤジからの便り、雨の日限定の手紙 など。

### 💬 会話をさらに増量
- **各施設での主要人物どうしの会話をさらに追加**(喫茶/市場/ゲーセン/本屋/ラーメン/銭湯/水族館/ケーキ屋/焼肉屋/居酒屋/花屋/屋上/路地)。
- **通常の主要人物の会話を増量**(各キャラに汎用・時間/天気/季節条件の会話を追加)。時間経過で入れ替わり、話しかけるたびの発見が増えます。

### 🍬 小暮カネ × 駄菓子屋のおばあさん
- 旧知の仲の二人の会話を実装(駄菓子屋・路地で発生)。ムニの話、焼き芋の話など、長年の付き合いがにじむやりとり。

### 🏠 親密度が上がると相互訪問 + その場で会話
- 主要人物どうしの**相互親密度が高くなると、互いの部屋に遊びに来る**ようになりました(閾値を50に緩和し、発生頻度もアップ)。
- **訪問先(自宅)での専用会話**を実装。レニィの雲ベッドでお昼寝、ネオの玉座に座る、ゲルの本棚を眺める…など、部屋ごとの会話。
- 仲の良い相手とは**一緒に施設へ出かけ**、その**施設でも会話が発生**します(v4のふるまいを会話面で強化)。

## 検証

```bash
node tools/validate.mjs   # 674ノード 全チェック合格
```

テストで確認済み: カネ×駄菓子屋の会話発火 / 相互親密度を上げると部屋への訪問(VISIT)が発生 / 訪問先での会話 / 施設ペア会話 / 通常会話が時間経過で23種以上に入れ替わること。

## v5で変更・追加した主なファイル

```
kowloon-life5/
├── js/
│   ├── data/
│   │   ├── dlg_v5.js    # ★新規: カネ×駄菓子屋 / 部屋訪問の会話 / 施設ペア増量 / 通常会話増量
│   │   └── letters.js   # 手紙25種に増量(S4便り/イベント礼状/カネ・床屋/雨の日)
│   └── sim/npc.js       # 相互訪問の閾値/頻度を調整(50以上で遊びに来やすく)
└── index.html / game.js # タイトル・セーブキーを v5 に
```

その他の中核システム(恋人/季節イベント/新施設/店/病気/泥棒/吹き出し等)は v4 と同一です。詳細は各版の README を参照してください。
