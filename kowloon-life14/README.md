# 九龍城ライフシミュレーター14 💬

`kowloon-life13`(v13)をベースに、**主要人物6人どうしの会話をさらに大幅増**した版(v14)です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life14_save_v1`)。会話ノード総数 **1280本** / 手紙 **41種**。

## 起動

```bash
cd kowloon-life14
python3 -m http.server 8000
# → http://localhost:8000
```

## v14 での追加(要望対応)

主要人物2人の立ち話を59本追加。要望のすべての「時」を網羅しています。

### 🏪 (A) 各施設来店時の通常ペア会話 — 16本
喫茶/ラーメン/本屋/駄菓子/ケーキ/ゲーセン/花屋/銭湯/水族館/居酒屋/玩具/コンビニ/焼肉/映画館/ドーナツ/教会。

### 💕 (B) 恋人どうしの通常会話 — 7組
カップル成立時のみ発火(rel==LOVER)。

### 💞 (C) 恋人どうしの各施設来店時 — 8本
喫茶/本屋/焼肉/銭湯/映画館/花屋/カラオケ/ドーナツで、恋人ならではの会話(rel==LOVER + 施設)。

### 🤝 (D) 友人どうしの通常会話 — 8組
恋人ではないが仲良くなった二人(mutual≧55 かつ rel≠LOVER)。

### 🍵 (E) 友人どうしの各施設来店時 — 8本
喫茶/ラーメン/本屋/ゲーセン/銭湯/水族館/ケーキ/カラオケで、親友どうしの会話(mutual≧55 かつ rel≠LOVER + 施設)。

### 🌤 (F) 時間帯・季節・天気ごとのペア会話 — 12本
朝/昼/夕/夜/真夜中、春夏秋冬、雨/晴れ/くもり。
