# アニメOPパロ・スタジオ 🎬

元動画のキャラクターを自分の指定したキャラに置き換えて、アニメOPトレースパロの
下絵・構図確認用プレビュー動画を作成するブラウザアプリです。
**すべての処理はブラウザ内で完結**し、動画や画像が外部へ送信されることはありません。

## 起動方法

ビルド不要の単一HTMLファイルです。

```bash
# このディレクトリで簡易サーバーを起動
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` をブラウザで直接開いても動作します(Chrome / Edge 推奨)。

## 画面構成と使い方

| 欄 | 内容 |
|---|---|
| **1. 置き換えキャラ画像** | 最大6人分のキャラ画像スロット。枠をクリックして選択し、画像をアップロード。名前も設定可能 |
| **2. キャラ対応付け** | クリック自動選択(色ベースの領域抽出)/ペイント塗りつぶし/消しゴムの3モード |
| **3. 元動画** | 元になる動画の読み込み欄+プレビュー+タイムライン |
| **4. 変換指示プロンプト** | どんな動画に変えたいかを文章で指示。クイックタグで定番の演出を追加 |
| **5. 完成アニメ** | 生成したプレビュー動画の表示欄。WebM形式でダウンロード可能 |
| **6. その他** | 生成設定・プロジェクト保存/読込・マスク/フレーム書き出し・外部AI API設定欄 |

### 基本フロー

1. **元動画を読み込む** — タイムラインにフィルムストリップ(サムネイル)が表示されます
2. **区間を選ぶ** — タイムライン上のシークバーを動かしながら、両端のハンドルをドラッグ、
   または「ここを開始点に / 終了点に」ボタンで変換したい区間を指定
3. **キャラを対応付ける** — キャラスロットを選択した状態で、動画プレビュー上の
   置き換えたい元キャラを **クリック(自動選択)** するか **ブラシで塗りつぶし**。
   スロットごとの色で塗り分けられ、対応表に反映されます
4. **プロンプトを書く** — 絵柄・雰囲気・演出の指示を入力
5. **「パロ動画を生成」** — 選択区間を再生しながら、塗った領域にキャラ画像を
   はめ込んだ置き換え合成プレビューを WebM 動画として生成します

### 外部AI生成APIについて

「その他」欄のAPI設定は拡張用のプレースホルダです。動画生成AIのAPIを接続すれば、
書き出したマスク画像・キャラ画像・プロンプトを送信して本格的な生成を行う構成に
拡張できます。未設定の場合はローカル合成プレビューで動作します。
