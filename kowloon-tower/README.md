# 九龍城タワー 🏙️

商業施設と6人の住人の家を九龍城のようにタワー状に積み上げていく箱庭ゲームです。
外装・内装・家具・キャラクターの3Dモデルはすべてコードでプロシージャル(自動)生成しています。

![Three.js](https://img.shields.io/badge/three.js-r160-blue)

## 遊び方

### 起動

ブラウザのESモジュールを使うため、ローカルサーバーで開きます。

```bash
cd kowloon-tower
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

(Node派の人は `npx serve .` でもOK)

### ゲームの流れ

1. **タワーを探索** — フロアをクリックすると中に入れます。各フロアは外階段でつながっています。
   - 初期タワー: スーパー / 喫茶店 / 床屋 / 郵便局 + 6人の自宅
2. **コインさがし 🪙** — コインは**商業施設のどこかに隠されています**。お店に入って、物陰で回る金色のコインを見つけてクリック。時間がたつとまた別の場所に隠されます。
3. **ガチャ 🎰** — 地上のガチャマシン(またはメニューのボタン)でコイン5枚につき1回。
   - **★★★ 新しい商業施設** — ラーメン屋・ゲームセンター・銭湯・本屋・駄菓子屋・花屋・カラオケ・薬局。「増築」でタワーのてっぺんに積み上がります(階段も自動でつながる)。
   - **★★ キャラのイメージ家具** — 6人それぞれの性格に合わせた家具。
   - **★ ふつうの家具**
4. **模様替え 🛋️** — 6人の自宅だけは内装を自由にカスタマイズできます。
   - 家具をクリックで選択 → **ドラッグで移動** / **回転** / **しまう**
   - 「もちもの」からガチャで手に入れた家具を配置
5. **住人と会話 💬** — 家にいる住人をクリックすると話しかけられます。

セーブは自動 (localStorage) です。

## 技術メモ

- **Three.js r160** (`lib/` に同梱、ビルド不要・完全オフライン動作)
- 3Dモデルは全てプリミティブ(Box/Cylinder/Sphere等)の組み合わせで自動生成
  - 外装: ネオン看板(Canvasテクスチャで日本語描画)・室外機・配管・ベランダ・洗濯物などをランダム生成
  - 内装: 施設タイプごとの専用ジェネレータ(12種) + 自宅
  - 家具: 28種 / キャラ: ちびキャラ6人
- 効果音はWebAudioでリアルタイム合成(音声ファイルなし)

### ファイル構成

```
kowloon-tower/
├── index.html      # UI・エントリポイント
├── js/
│   ├── data.js     # キャラ/施設/家具/ガチャ/セリフ定義
│   ├── prims.js    # プリミティブ生成ヘルパー・看板テクスチャ
│   ├── floors.js   # 外装ファサード・内装12種・階段・屋上・地上
│   ├── furniture.js# 家具28種のジェネレータ
│   ├── characters.js # キャラ6人のモデル生成
│   └── main.js     # ゲームロジック(カメラ/コイン/ガチャ/模様替え/セーブ)
└── lib/            # three.js (vendored)
```
