# 🏛 3D建築アトリエ

画像とことば(日本語)から、**建物の外観・部屋の内装・家具** を3Dモデルとして生成し、
GLB / OBJ 形式でダウンロードできるブラウザアプリです。
すべてブラウザ内で完結し、サーバーへのアップロードは一切ありません。

## 起動方法

ビルド不要です。このフォルダで簡易HTTPサーバーを立てるだけで動きます。

```bash
cd atelier3d
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

(ES Modules を使っているため、`index.html` を直接ダブルクリックではなく
HTTPサーバー経由で開いてください)

## 使い方

1. **作るもの** を選ぶ(自動判定 / 建物の外観 / 内装(部屋) / 家具)
2. **文章で指示** に日本語で書く
   - 「赤いレンガの3階建てのカフェ。三角屋根でベランダ付き。」
   - 「石造りの城。庭とプール付き」
   - 「8畳の寝室。ベッドと青いソファと観葉植物2つ」
   - 「赤いソファと椅子4脚と木のテーブル」
3. **参考画像** をドロップ(任意・複数可)
   - **部屋や家具の写真** → 写っている家具(ソファ・椅子・テーブル・テレビ・ベッド・冷蔵庫・観葉植物 など)を
     ブラウザ内の物体認識(TensorFlow.js + COCO-SSD)で自動検出し、
     **写真内の位置と色を保ったまま全て3D化** します
   - **建物の外観写真** → 壁の質感(レンガ / 石 / 木 / コンクリ / ガラス / 塗り壁)と色を推定して反映します
   - **素材写真(レンガ・木目など)** → 外壁・屋根・壁紙・床などの質感テクスチャとして使用します
   - 役割はサムネイルのプルダウンでいつでも手動指定できます
4. **テクスチャ品質** を選ぶ(1K / 2K / 4K / **8K**)
5. **「3Dモデルを生成」** を押す
6. **テストプレイ** — 生成したモデルの中や周囲を歩いて確認できます
   - `W A S D` / 矢印キー: 移動、マウス: 見回し、`Shift`: ダッシュ、`Esc`: 終了
7. **ダウンロード**
   - **GLB**: テクスチャ埋め込み済み。Blender / Unity / Unreal / 各種ビューアでそのまま開けます
   - **OBJ**: 形状のみ
   - **スクリーンショット**: 現在のビューをPNG保存

## 画像認識について

- 物体認識モデル(COCO-SSD ssdlite_mobilenet_v2、約18MB)は `vendor/tf/` に同梱されており、
  **完全にオフライン・ブラウザ内** で動作します。画像が外部に送信されることはありません。
- 認識できる家具: ソファ・椅子・ベッド・テーブル・テレビ・観葉植物・冷蔵庫・トイレ・シンク・時計・電子レンジ/オーブン(→キッチン)・本(→本棚)・ベンチ など
- 検出結果はサムネイルの下に表示されます。文章の指示と画像の両方がある場合は**両方とも**反映されます。
- 家具が検出されなかった画像は、従来どおり質感テクスチャとして使われます。

## テクスチャ品質と8Kについて

- 生成パターン(レンガ・木目・瓦など)は **タイリング** で貼られるため、2Kテクスチャでも壁一面では8K相当の密度になります。
  このため生成パターンは最大2048pxで作られ、**8K設定はアップロード画像の解像度**(最大8192px)に効きます。
- GPUの上限(`MAX_TEXTURE_SIZE`)を超える解像度は自動的にクランプされ、
  以前のように**8Kでメモリを使い切って画面が白くなる問題は起きません**。
  万一GPUメモリが不足した場合もエラーメッセージを表示して復帰できます。

## 技術構成

- [Three.js](https://threejs.org/) r160(`vendor/` に同梱、オフラインでも動作)
- [TensorFlow.js](https://www.tensorflow.org/js) + COCO-SSD による物体認識(`vendor/tf/` に同梱)
- テクスチャはCanvas 2Dでプロシージャル生成(レンガ・石・タイル・金属・木目・瓦・漆喰・畳・和紙・布 など)+ バンプマップで立体感を表現
- 窓・手すり等はジオメトリ結合で軽量化(高層タワーでも軽快に動作)
- テクスチャは (種類×リピート) 単位でキャッシュし、GPUへの重複アップロードを排除
- 書き出しは `GLTFExporter`(バイナリGLB・テクスチャ埋め込み)/ `OBJExporter`

## テスト
