# 🏛 3D建築アトリエ

画像とことば(日本語)から、**建物の外観・部屋の内装・家具** を3Dモデルとして生成し、
GLB / OBJ 形式でダウンロードできるブラウザアプリです。
すべてブラウザ内で完結し、サーバーへのアップロードは一切ありません。

## 起動方法

ビルド不要です。このフォルダで簡易HTTPサーバーを立てるだけで動きます。

```bash
cd atelier3d
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

(ES Modules を使っているため、`index.html` を直接ダブルクリックではなく
HTTPサーバー経由で開いてください)

## 使い方

1. **作るもの** を選ぶ(自動判定 / 建物の外観 / 内装(部屋) / 家具)
2. **文章で指示** に日本語で書く
   - 「赤いレンガの3階建てのカフェ。三角屋根でベランダ付き。」
   - 「ガラス張りの20階建てのタワー」
   - 「木の床の広いリビング。ソファとテーブルとテレビと本棚。」
   - 「青いソファ」「木製のテーブルと椅子とランプ」
3. **参考画像** をドロップ(任意・複数可)
   - 画像は外壁・屋根・壁紙・床・家具などのテクスチャとして反映されます
   - 役割はサムネイルのプルダウンで指定(既定は自動割り当て)
   - 画像から代表色も抽出され、モデルの配色に使われます
   - 8192px までの高解像度画像に対応
4. **テクスチャ品質** を選ぶ(1K / 2K / 4K / **8K**)
5. **「3Dモデルを生成」** を押す
6. **テストプレイ** — 生成したモデルの中や周囲を歩いて確認できます
   - `W A S D` / 矢印キー: 移動、マウス: 見回し、`Shift`: ダッシュ、`Esc`: 終了
7. **ダウンロード**
   - **GLB**: テクスチャ埋め込み済み。Blender / Unity / Unreal / 各種ビューアでそのまま開けます
   - **OBJ**: 形状のみ
   - **スクリーンショット**: 現在のビューをPNG保存

## 指示文で使えるキーワード(抜粋)

| 種類 | キーワード例 |
|---|---|
| 建物タイプ | 一軒家・小屋・マンション・アパート・ビル・オフィス・タワー・店・カフェ |
| 階数 | 「3階建て」「平屋」(1〜40階) |
| 屋根 | 三角屋根・切妻 / 平ら・陸屋根 |
| 外装 | レンガ・木造・コンクリ打ちっぱなし・ガラス張り・モダン・和風 |
| 色 | 白い・黒い・赤い・青い・緑・黄色・茶色・ベージュ・グレー・ピンク・ネイビー など |
| 付属 | ベランダ・バルコニー |
| 部屋 | リビング・寝室・和室・広い・カーペット・畳 |
| 家具 | ベッド・ソファ・テーブル・机・椅子・本棚・ランプ・テレビ・ラグ・観葉植物・クローゼット・キッチン |

## 8Kモデルについて

テクスチャ品質で **8K** を選ぶと 8192×8192 のテクスチャで生成・書き出しされます。
最高精細ですが、生成に数十秒・GLB書き出しに大きなメモリを使うため、高性能なPCを推奨します。
アップロード画像もリサイズなし(最大8192px)でGLBに埋め込まれます。

## 技術構成

- [Three.js](https://threejs.org/) r160(`vendor/` に同梱、オフラインでも動作)
- テクスチャはCanvas 2Dでプロシージャル生成(レンガ・木目・瓦・漆喰・布 など)
- 窓・手すり等はジオメトリ結合で軽量化(高層タワーでも軽快に動作)
- 書き出しは `GLTFExporter`(バイナリGLB・テクスチャ埋め込み)/ `OBJExporter`

## テスト

Playwright によるスモークテスト(生成 → GLB/OBJ書き出し → テストプレイ開始/終了)で
全モードの動作を確認済みです。
