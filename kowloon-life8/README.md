# 九龍城ライフシミュレーター8 🎬

`kowloon-life7`(v7)をベースに、**映画館・ドーナツ屋・集会所イベント(ひな祭り/怪談/夏祭り/誕生日会)を追加し、主要人物どうしの会話を大幅に増やした版(v8)**です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life8_save_v1`)。会話ノード総数 **917本** / 手紙 **38種**。

## 起動

```bash
cd kowloon-life8
python3 -m http.server 8000
# → http://localhost:8000
```

## v8 での追加(要望対応)

### 🎬 映画館「シネマ・ホシカゲ」+ 館長 星影幸太郎
- 映画館をガチャに追加。大スクリーン・赤いカーテン・客席・映写窓・ポスターを自動生成。
- **星影幸太郎(館長)** を追加。蝶ネクタイがトレードマークの映画狂で、語り出すと止まらない。オールバックの黒髪。
- 主要人物6人、**床屋のオヤジ、郵便屋**と映画談義。初対面イベント・各キャラ専用会話つき。

### 🍩 ドーナツ屋「ドーナツ九龍」
- ドーナツ屋をガチャに追加。色とりどりのドーナツのショーケース・丸テーブルを自動生成。
- 全キャラが来店するが、**ムニは特によく来る**(スケジュールで来店頻度を高めに設定)。

### 🎎 集会所の季節イベントを大量追加
- **ひな祭り**(春): その日だけ雛人形(段飾り)を飾り、翌日に消去。みんなで集合、仲良くなればカネも来る。
- **怪談クラブの日**(夏): 灯りを落として怖い話。ゲルが一番怖い話をし、ジンパチが半泣きに。
- **ミニ夏祭りの日**(夏): 金魚すくい・りんご飴の屋台が出る。提灯の下でみんなが賑わう。
- **誕生日会6種**: 春=ムニ / 夏=ヒュウ・レニィ / 秋=ゲル・ジンパチ / 冬=ネオ・小暮カネ(親密度上昇時のみ本人が来る)。ケーキと風船を飾り、みんなでお祝い。

### ☕ サチ × リン 喫茶店でのガールズトーク
- リンが休憩時間に喫茶店へ立ち寄るようスケジュール調整。**サチとリンが喫茶店で会えるように**。
- 「**恋人にするなら誰?**(ムニ以外の5人・ゲルも含む)」のガールズトークを複数追加。

### 💬 主要人物どうしの会話を大幅増(特に施設/店)
- **各施設での通常ペア会話**を増量(映画館・ドーナツ屋含む)。
- **恋人どうしが施設に一緒にいるとき**の会話(喫茶店デート・焼肉・映画館・水族館…)。
- **親しい友人(恋人ではない)が施設に一緒にいるとき**の会話。
- **カラオケの複数人デュエット/トリオ/カルテット**(2人以上で来て一緒に歌う)。

### ✉️ 手紙を増量(32種 → 38種)
- 星影館長・ムニ(ひな祭り)・ヒュウ(夏祭り)・ネオ(誕生日の礼状)・サチ&リン連名・ゲル(怪談の夜)からの便り。

### 🤝 親密度による相互訪問(既存機能を継続)
- 相互親密度が高いと、互いの部屋に遊びに来たり、一緒に施設へ出かける(会話も発生)。
