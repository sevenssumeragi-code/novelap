# 九龍城ライフシミュレーター15 🎄

`kowloon-life14`(v14)をベースに、**喧嘩・仲直りシステム / 季節日数の延長 / 集会所イベント会話の増量 / クリスマス深夜のプレゼント / 主要人物ペア会話のさらなる増量**を加えた版(v15)です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life15_save_v1`)。会話ノード総数 **1321本** / 手紙 **41種**。

## 起動

```bash
cd kowloon-life15
python3 -m http.server 8000
# → http://localhost:8000
```

## v15 での追加(要望対応)

### 💢 喧嘩・仲直りシステム
- 主要人物2人の**相互親密度が一定以下(28未満)だと喧嘩が起こる**(ゲル×ネオ、ヒュウ×ネオ、ジンパチ×ネオ、レニィ×ネオ、ヒュウ×ゲルなど、まだ打ち解けていない組)。
- 喧嘩した相手とは**1日以上経ってから再会すると仲直り**し、相互親密度が上がる。仲直り後は喧嘩しなくなる。
- 実装: 世界状態に `quarrels`(喧嘩開始日)を追加。DSLに `quarreling(A,B)` / `quarrel_days(A,B)`、効果に `quarrel()` / `reconcile()` を追加。セーブ対応済み。

### 📅 各季節の日数を延長(8日 → 14日)
- 集会所イベントの日が増えたため、1季節を14日に延長。イベントの合間にゆとりが生まれる。

### 🎉 集会所イベント(誕生日/クリスマス等)の会話を大幅増
- お花見・クリスマス・正月・ハロウィン・誕生日会(ムニ/ネオ/ゲル)などに**別バージョンの集合会話**を追加。同じイベントでも毎回違う掛け合いに。

### 🎁 クリスマス深夜のプレゼント + 翌朝の開封
- **クリスマスの深夜、5人のうち誰か(その日ごとに変わる)がムニの部屋にそっとプレゼントを届ける**シーン。ムニは寝ぼけて「サンタさん?」とつぶやく。
- **翌朝、ムニが枕元のプレゼントを見つけて大喜びで開ける**場面。「ゆうべ、だれかのこえがきこえた気がするの……みんな、やさしいね」。

### 💬 主要人物6人どうしの会話をさらに大幅増
- 各施設来店時・恋人時・友人時・恋人/友人×各施設・時間帯/季節/天気ごとのペア会話を追加。
