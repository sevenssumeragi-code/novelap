# 九龍城ライフシミュレーター3 🏙️

`kowloon-life2`(v2)をベースにした**改善版(v3)**です。テストプレイ機能の追加、新NPC・新施設、会話バリエーションの拡充を行いました。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life3_save_v1`)。会話ノード総数 **508本**。

## 起動

```bash
cd kowloon-life3
python3 -m http.server 8000
# → http://localhost:8000
```

## v3 での追加・修正(要望対応)

### 🧪 テストプレイ機能(完成時に消去可能)
- **初期コイン7000枚**(圓も9000)でスタート。
- 画面右下の **🧪 テスト** ボタンでパネルを開き、**スイッチひとつで全キャラの好感度を「他人〜唯一無二」に設定**(個別設定も可)。「全施設をアンロック&建設」ボタンも搭載。
- これらは **`js/testtools.js`(独立モジュール)に完全隔離**。ゲーム完成時は以下だけで消えます:
  1. `js/testtools.js` を削除
  2. `js/game.js` の `export const TEST_MODE = true;` を `false` に(初期コインも 0 に戻ります)
  3. `js/game.js` 末尾の `if (TEST_MODE) { import('./testtools.js')… }` ブロックを削除
  本体は `window.__kl` 経由でのみ操作されるため、テストコードへの依存はありません。

### 🍬 駄菓子屋のおばあさん(新NPC)
- 「駄菓子屋のおばあさん」を店番NPCとして追加(エプロン姿の3Dモデル、駄菓子屋に常駐)。ムニとの定番のやりとり、初対面イベント、店内会話を実装。

### 🤖 ジンパチのプラモデル趣味
- プロフィールに「プラモデル作りが趣味」を追加。**プラモについての会話**を複数追加。
- **玩具屋(おもちゃ屋ポン)を新施設として追加**。ジンパチは玩具屋で新作プラモを見つけると人が変わったようにはしゃぎます。
- **家具「プラモデル展示棚」を追加**(ガラスケースにロボ&戦艦プラモの3Dモデル)。
- **お願いクエスト**: ジンパチが「プラモを飾る展示棚が欲しい」と頼み、`jin_plamo` を部屋に置くと、喜んでお礼(親密度+6・コイン)を言う会話が発生。

### 💊 薬局に主要人物が来るように
- 6人のスケジュールに薬局を組み込み、薬局での会話を大幅増量(湿布・目薬・栄養ドリンク・絆創膏など各キャラの反応)。主要人物どうしの薬局会話も追加。

### 🎤 カラオケに他キャラも来るように
- ヒュウ以外(レニィ/ジンパチ/ムニ/ゲル/ネオ)の夕方スケジュールにカラオケを追加。3人グループ会話やネオ×ゲルの採点会話など、賑やかに。

### 🗣️ 各施設での主要人物どうしの会話を増量
- 喫茶/ラーメン/ゲーセン/本屋/花屋/玩具屋/薬局/カラオケ/市場/居酒屋など、**施設ごとに主要人物ペアの立ち話(AMBIENT)を追加**。

### 🥷 コンビニで泥棒と鉢合わせ
- **コンビニ九龍(24時間営業)を新施設として追加**。**コソ泥NPC**(覆面の3Dモデル)がコンビニに潜みます。
- **主要6人それぞれ**とコソ泥が鉢合わせたときの専用会話を実装(ジンパチは追いかけ、ネオは騎士として成敗、ムニは純粋に話しかけ、ゲルは見透かし、ヒュウは美しく諭し、レニィはおにぎりをおごる)。プレイヤーがコソ泥に話しかけると撃退イベント(コイン獲得、撃退回数で会話変化)。

## 検証

```bash
node tools/validate.mjs   # 508ノード 全チェック合格
```

## v3で変更・追加した主なファイル

```
kowloon-life3/
├── js/
│   ├── testtools.js       # ★新規: テストプレイ用(好感度スイッチ等・削除可能)
│   ├── data/
│   │   ├── chars.js       # ジンパチにプラモ趣味 / 駄菓子屋ばあさん・コソ泥 追加 / ペア拡張
│   │   ├── facilities.js  # 玩具屋・コンビニ 追加
│   │   ├── schedules.js   # 薬局・カラオケ・玩具屋・コンビニへの誘導 + 新NPC勤務
│   │   ├── facility_talk.js # 玩具屋・コンビニ 施設会話 + 薬局増量
│   │   ├── furniture.js   # プラモデル展示棚 追加
│   │   ├── dlg_v3.js      # ★新規: プラモ/駄菓子屋/泥棒鉢合わせ/施設ペア会話
│   │   └── registry.js    # 新フラグ・INFO登録
│   ├── three/
│   │   ├── floors.js      # 玩具屋・コンビニ の内装ジェネレータ
│   │   ├── furnituregen.js # プラモデル展示棚の3Dモデル
│   │   └── characters.js  # コソ泥(覆面)・駄菓子屋(エプロン)の見た目
│   ├── sim/dialogue.js    # dlg_v3 を合流
│   └── game.js            # TEST_MODE / 初期コイン7000 / プラモ完成判定
└── tools/validate.mjs
```

その他の中核システムは v1/v2 と同一です。詳細は `../kowloon-life/README.md`・`../kowloon-life2/README.md` を参照してください。
