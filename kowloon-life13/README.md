# 九龍城ライフシミュレーター13 🎆

`kowloon-life12`(v12)をベースに、**星影館長の老人口調化・こどもの日/花火大会イベント・各施設ペア会話の大幅増**を加えた版(v13)です。

Three.js 同梱・ビルド不要・完全オフライン。セーブは独立枠(`kowloon_life13_save_v1`)。会話ノード総数 **1221本** / 手紙 **41種**。

## 起動

```bash
cd kowloon-life13
python3 -m http.server 8000
# → http://localhost:8000
```

## v13 での追加(要望対応)

### 🎬 星影幸太郎(映画館館長)を老人口調に変更
- 一人称「わし」、二人称「おぬし」、語尾「〜のう」「〜じゃ」の好々爺に。会話・手紙・辞典まで全セリフを老人口調へ統一。

### 🎏 こどもの日イベント(集会所)
- 夏の特定日に発生。集会所に**鯉のぼり(大中小の真鯉・緋鯉・子鯉+吹き流し)**を自動生成(翌日撤去)。主要人物みんなで集まり、仲良くなればカネも参加。

### 🎆 花火大会イベント(屋上)
- 夏の特定日の夕〜夜に発生。**九龍城の外の夜空に花火が打ち上がる**(打ち上げ→大輪に開いて重力でしだれるアニメーション)。主要人物が屋上に集まって花火を見上げる。仲良くなればカネも参加。
- イベント会場(venue)を集会所以外(屋上)にも指定できるよう、イベント基盤を拡張。

### 🏪 各施設での主要人物ペア会話を大幅増(特に要望対応)
- **通常**のペア会話(喫茶/ラーメン/本屋/駄菓子/ケーキ/ゲーセン/花屋/銭湯/水族館/居酒屋/玩具/コンビニ/映画館/ドーナツ/教会)を15本。
- **恋人どうしが施設に一緒にいるとき**の会話を8本(rel==LOVER)。
- **親しい友人(恋人でない)が施設に一緒にいるとき**の会話を8本(mutual≧55 かつ rel≠LOVER)。

### 🏠 親密度が高いと互いの部屋に遊びに来る + そこでの会話
- 相互親密度が高いペアが互いの自宅を訪問(既存機能)し、**訪問先の部屋での専用会話**を8組追加(レニィの雲ベッド、ヒュウの鏡部屋、ジンパチのプラモ棚、ゲルの書斎…)。

### 🎤 カラオケの複数人デュエット/合唱を増量
- 三重唱・男二人デュエット・凸凹デュエット・五人合唱など、2人以上で歌う会話を追加。

### ✉️ 手紙を増量(38種 → 41種)
- ジンパチ(こどもの日)・ヒュウ(花火大会)・ネオ(花火の感慨)からの便り。
